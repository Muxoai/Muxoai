## What we're building

Muxo is a hosted MCP server that gives the AI assistant you already use real hands. Connect it
once to Claude Code, Codex, Cursor, Droid, ChatGPT or Claude Desktop, and your assistant can
provision databases, caches, storage and hosting; call apps, APIs and research tools; and change
things in GitHub, Slack, Gmail, Linear, Notion, Stripe and more — with every action checked
against your rules and recorded with a receipt.

- **Provision cloud** on 53 providers — Neon, Supabase, Turso, Upstash, Cloudflare, Vercel and more.
- **Call 1,700+ apps and APIs**, plus 73 instant toolkits that need no sign-in and 10 built-in
  checks for DNS, TLS, security headers and dependencies.
- **Reads run right away; changes wait for your OK.** Money, new cloud resources, access changes
  and deletes wait for a workspace owner or admin.
- **Credentials never appear in chat**, and every run has a receipt.

Built for solo developers, founders and small dev teams.

## Start

```sh
# Claude Code
claude mcp add --transport http muxo https://api.muxo.ai/mcp

# Codex
codex mcp add muxo --url https://api.muxo.ai/mcp
```

Cursor, Droid, ChatGPT and Claude Desktop: see the [quickstart](https://docs.muxo.ai/quickstart).
